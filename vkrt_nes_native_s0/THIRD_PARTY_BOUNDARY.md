# Third-party boundary

This product is a first-party clean-room implementation from public hardware
concepts. There is no imported/copied/linked third-party emulator implementation.
Its only build/runtime facilities are the already-installed C++20 standard
library, compiler, CMake/Ninja, and stdlib-only Python validation scripts.

No SimpleNES, Mesen, FCEUX, Nestopia, libretro, Lakesnes, SDL, SFML, miniaudio,
vendor DLSS/FSR binaries or other emulator core is a dependency. No package
manager, FetchContent, ExternalProject, download URL, network access, generated
download script, emulator adapter linkage or parent-project include is needed.

First-party VKRT products were inspected read-only for snapshot ownership,
provenance, identity ambiguity, temporal confidence, tests and claim discipline.
Historical adapters in those products may use external cores; none of those
adapters or dependencies is brought into this product. No first-party runtime
code outside this product is linked either.

The synthetic iNES program and simple bitmap glyphs/patterns are generated by
`src/witness.cpp`. No .nes/.fds/.unf/.unif files, commercial ROM bytes, proprietary
assets, external palettes or downloaded conformance ROMs are included as source.
M1 bank/IRQ tests generate additional synthetic iNES images entirely in memory.
No binary ROM fixture is stored under this product.

M1 separately reads the task-authorized operator ROM outside `products/` as a
behavioral compatibility witness. Its bytes are never copied into source or
evidence, emitted, disassembled, used as implementation authority, or selected
by a game-specific runtime condition. Generated PPM/semantic/audio observations
are local evidence, not imported source assets. The input remains read-only.
Only documentation/receipts bind the witness identity; machine behavior has no
title/hash special cases. No third-party core, DLL or subprocess executes it.
